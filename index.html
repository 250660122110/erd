Latar Belakang

SMK YPPM TOMO merupakan lembaga pendidikan yang sedang berkembang pesat. Seiring bertambahnya jumlah siswa, guru, dan rombongan belajar, proses manajemen administrasi akademik yang bersifat manual mulai menemui kendala efisiensi.

Oleh karena itu, sekolah memerlukan sistem basis data terpadu yang mampu mengelola data akademik secara terstruktur dan relasional untuk menjamin konsistensi data.

Rumusan Tantangan

Menghubungkan data guru pengajar, penjadwalan kelas, pendaftaran siswa, hingga kalkulasi nilai akhir semester dalam satu arsitektur database yang aman, konsisten, dan minim redundansi.

Analisis Kebutuhan

Identifikasi objek data esensial yang wajib dikelola secara komprehensif dalam sistem informasi akademik:

👨‍🏫

1. Guru

Mengelola identitas tenaga pengajar, kontak, alamat, serta penugasan wali kelas maupun mata pelajaran.

👨‍🎓

2. Siswa

Mengelola data personal peserta didik, nomor induk nasional, riwayat kelas, dan rekam akademis.

🏫

3. Kelas

Mengelola penamaan kelas, pembagian jurusan (TKJ, Akuntansi, dll), tingkatan, serta pendamping kelas (wali).

📚

4. Mata Pelajaran

Katalog kurikulum mata pelajaran wajib dan muatan lokal beserta batas kriteria ketuntasan minimal (KKM).

📅

5. Jadwal

Integrasi hari, jam, kelas, guru pengajar, dan mata pelajaran guna mencegah jadwal ganda (clash).

💯

6. Nilai

Penyimpanan nilai tugas, UTS, UAS, serta formulasi nilai akhir siswa per mata pelajaran di tiap semester.

Relasi Antar Database

Guru (NIP)
Kelas (id_kelas, nip)
Siswa (nis, id_kelas)
Jadwal (id_kelas, nip, kode_mapel)
Mata Pelajaran (kode_mapel)
Nilai (nis, kode_mapel)
1. Guru ➜ Kelas (1:M) Seorang Guru dapat menjadi wali kelas maksimal untuk 1 kelas, namun setiap kelas wajib dibimbing oleh 1 wali kelas (Primary Key NIP dipasang di tabel kelas).
2. Kelas ➜ Siswa (1:M) Sebuah kelas menampung banyak siswa, namun seorang siswa hanya terdaftar pada 1 kelas tertentu (id_kelas berstatus Foreign Key di tabel Siswa).
3. Kelas / Guru / Mapel ➜ Jadwal (1:M) Sebuah jadwal pelajaran merepresentasikan relasi pertemuan yang menghubungkan 1 kelas, 1 guru pengampu, dan 1 mata pelajaran spesifik.
4. Siswa / Mapel ➜ Nilai (1:M) Setiap entri nilai mendefinisikan capaian akademis dari 1 siswa terhadap 1 mata pelajaran untuk semester tertentu.

Langkah Implementasi XAMPP

Langkah 1

Instal dan Buka XAMPP

Unduh paket instalasi XAMPP dari Apache Friends. Lakukan instalasi pada direktori komputer lokal Anda (biasanya di C:\xampp) kemudian buka aplikasi XAMPP Control Panel.

Langkah 2

Jalankan Apache & MySQL

Pada baris modul Apache dan MySQL, klik tombol Start hingga indikator status berubah menjadi warna hijau dan port pengaktifan ditampilkan.

Langkah 3

Buka phpMyAdmin

Buka peramban browser pilihan Anda (Chrome/Firefox/Edge) lalu ketikkan tautan administrasi basis data lokal berikut pada bilah alamat:

http://localhost/phpmyadmin
Langkah 4

Inisiasi Database

Pilih menu 'SQL' di phpMyAdmin untuk menginisiasi skema database baru khusus SMK YPPM TOMO menggunakan perintah DDL:

CREATE DATABASE db_smk_yppm_tomo;

Pembuatan Tabel (DDL Query)

MySQL Code 
-- Pembuatan Tabel Guru Master --
CREATE TABLE guru (
  nip VARCHAR(20) PRIMARY KEY,
  nama_guru VARCHAR(100) NOT NULL,
  jenis_kelamin ENUM('L','P'),
  no_hp VARCHAR(15),
  alamat TEXT
);
-- Pembuatan Tabel Kelas dengan Relasi Wali Kelas --
CREATE TABLE kelas (
  id_kelas INT AUTO_INCREMENT PRIMARY KEY,
  nama_kelas VARCHAR(50) NOT NULL,
  jurusan VARCHAR(50),
  tingkat VARCHAR(10),
  nip VARCHAR(20),
  FOREIGN KEY (nip) REFERENCES guru(nip)
  ON DELETE SET NULL ON UPDATE CASCADE
);
-- Pembuatan Tabel Siswa Master Berelasi ke Kelas --
CREATE TABLE siswa (
  nis VARCHAR(20) PRIMARY KEY,
  nisn VARCHAR(20) UNIQUE,
  nama_siswa VARCHAR(100) NOT NULL,
  jenis_kelamin ENUM('L','P'),
  tgl_lahir DATE,
  alamat TEXT,
  id_kelas INT,
  FOREIGN KEY (id_kelas) REFERENCES kelas(id_kelas)
  ON DELETE SET NULL ON UPDATE CASCADE
);
-- Pembuatan Tabel Katalog Mata Pelajaran --
CREATE TABLE mata_pelajaran (
  kode_mapel VARCHAR(15) PRIMARY KEY,
  nama_mapel VARCHAR(100) NOT NULL,
  kkm INT DEFAULT 75
);
-- Pembuatan Tabel Jadwal Pelajaran (Relasi M-to-M) --
CREATE TABLE jadwal (
  id_jadwal INT AUTO_INCREMENT PRIMARY KEY,
  id_kelas INT,
  nip VARCHAR(20),
  kode_mapel VARCHAR(15),
  hari VARCHAR(15),
  jam TIME,
  FOREIGN KEY (id_kelas) REFERENCES kelas(id_kelas),
  FOREIGN KEY (nip) REFERENCES guru(nip),
  FOREIGN KEY (kode_mapel) REFERENCES mata_pelajaran(kode_mapel)
);
-- Pembuatan Tabel Rekam Nilai Akademik Siswa --
CREATE TABLE nilai (
  id_nilai INT AUTO_INCREMENT PRIMARY KEY,
  nis VARCHAR(20),
  kode_mapel VARCHAR(15),
  semester INT,
  tugas DECIMAL(5,2),
  uts DECIMAL(5,2),
  uas DECIMAL(5,2),
  nilai_akhir DECIMAL(5,2) GENERATED ALWAYS AS 
  ((tugas * 0.3) + (uts * 0.3) + (uas * 0.4)) STORED,
  FOREIGN KEY (nis) REFERENCES siswa(nis),
  FOREIGN KEY (kode_mapel) REFERENCES mata_pelajaran(kode_mapel)
);

Pengisian Contoh Data (INSERT)

Untuk memverifikasi skema database, berikut adalah baris skrip DML (Data Manipulation Language) yang digunakan untuk menyisipkan data sampel ke dalam masing-masing tabel:

DML SQL Query 
-- Menyisipkan Data Master Guru --
INSERT INTO guru VALUES 
('1987001', 'Bambang Liman Maulana, S.Pd.', 'L', '081234567890', 'Tomo Sumedang'),
('1989002', 'Siti Rahmawati, S.Kom.', 'P', '085721113222', 'Jatigede');

-- Menyisipkan Data Master Kelas --
INSERT INTO kelas (nama_kelas, jurusan, tingkat, nip) VALUES 
('X-RPL-1', 'Rekayasa Perangkat Lunak', '10', '1989002');

-- Menyisipkan Data Master Siswa --
INSERT INTO siswa VALUES 
('20261001', '0087451290', 'Aditya Nugraha', 'L', '2010-04-12', 'Tomo', 1),
('20261002', '0088912301', 'Lilis Karlina', 'P', '2010-09-25', 'Ujungjaya', 1);
